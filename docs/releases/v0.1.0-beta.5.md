Removent `0.1.0-beta.5`，面向 **Apple Silicon Mac、macOS 13 及以上**。

Removent `0.1.0-beta.5` for **Apple Silicon Macs running macOS 13 or later**.

### 新增 / Added

- 连接可保存为收藏：连接表单新增可选备注名，提交的连接写入 connections.json，之后可从侧栏一键重连、编辑或删除。
- Connections can be saved as bookmarks: the form gains an optional memo name, submitted connections persist to connections.json, and the sidebar reconnects, edits, or removes them.
- 收藏密码保存在 macOS 钥匙串，磁盘仅记录是否使用密码；重连时自动读取凭据，编辑时可查看、修改或清除。
- Bookmark passwords live in the macOS Keychain while disk only records whether one exists. Reconnecting reads the secret back, and editing can view, change, or clear it.

### 改进 / Changed

- 应用、后台服务和菜单栏标识统一更名为 `com.alkinum.removent.*`，覆盖安装启动器、launchd 任务、登录项、钥匙串服务和屏幕录制自身排除，启动时清理旧标识注册。
- The app, background service, and menu bar identifiers move to `com.alkinum.removent.*`, covering the installer launcher, launchd jobs, login items, the Keychain service, and the capture self-exclusion; legacy registrations are retired on startup.
- 空状态引导在详情面板中垂直居中，窗口过矮时仍可滚动查看。
- The empty-state guide centers vertically in the detail panel while remaining scrollable in short windows.

### 修复 / Fixed

- 连接 macOS 屏幕共享时右键与中键互换：Apple greeting 下的 PointerEvent 现在始终使用 RFC 6143 标准按键顺序。
- Right and middle clicks were swapped on macOS Screen Sharing connections; PointerEvent now always uses the RFC 6143 button order, including after Apple authentication.
- 更新检查对临时网络与服务器错误自动重试，错误提示区分 HTTP 状态、DNS、连接、超时和 TLS 失败，重试不再拼接损坏的清单。
- Update checks retry transient network and server errors, distinguish HTTP status, DNS, connection, timeout, and TLS failures, and no longer splice partial manifests across retries.

### 安装与兼容性 / Installation and compatibility

- **从 beta.4 升级必须重新安装**：应用标识由 `io.removent.app` 更名为 `com.alkinum.removent`，beta.4 的应用内更新会拒绝新包。请下载 DMG 重新安装；macOS 可能重新请求屏幕录制与辅助功能权限。
- **Upgrading from beta.4 requires a reinstall**: the bundle identifier moved from `io.removent.app` to `com.alkinum.removent`, so the beta.4 in-app updater rejects this build. Download the DMG and reinstall; macOS may re-prompt for Screen Recording and Accessibility.
- 已知问题：旧版本注册的「登录时启动」偏好和 launchd 任务在重装后可能不会自动接管，若开机不再自动运行请重新开启对应选项；收藏的编辑与多窗口并发写入也存在已知边界情况。完整清单见 `docs/review-2026-09-13.md`。
- Known issues: login-launch preferences and launchd jobs registered by earlier betas may not be taken over after reinstalling — re-enable the options if automatic startup stops — and bookmark editing plus concurrent writes from multiple windows still have known edge cases. See `docs/review-2026-09-13.md` for the full list.
- 协议版本仍为 **RVP 1**，本次未修改网络消息格式。
- The native protocol remains **RVP 1**, with no wire-format changes in this release.
