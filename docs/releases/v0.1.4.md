Removent `0.1.4` is a stable release. RVP remains protocol v1. The desktop app requires Apple Silicon and macOS 26 or later; the standalone relay supports Linux x86_64 / ARM64 and macOS Universal on macOS 13 or later.

## Authentication and connections

- Desktop and iPhone/iPad controllers follow the host's pairing-code, access-password, authenticator OTP or no-authentication policy. Password and OTP use SPAKE2 proofs and signed mutual confirmation; OTP codes are single-use. No-authentication mode retains encrypted RVP transport and host certificate verification.
- Direct and relay sessions use the same host authentication. Relay access credentials and registered-device proofs are checked separately. Regression coverage exercises every host mode through QUIC and WebSocket relay carriers, including rejected credentials.
- Connection recovery is bounded and shared by desktop and mobile. Offline sessions retain the picture, pause input and audio, and retry when a route returns. Reconnects pin the authenticated host; policy changes cannot reuse an old resume grant.
- LAN discovery uses Bonjour/mDNS broadcasts for Removent, VNC and RDP. Unadvertised servers can be added manually. Saved connections hide matching advertised devices without merging credentials or pairing trust.

## Settings and updates

- Settings has a narrower, left-aligned sidebar, clearer light/dark surfaces and a compact appearance preview. Access-password setup keeps the previous mode active until a valid password is saved. OTP keys and QR codes are shown on request and hidden when leaving the page; mobile OTP entry supports system AutoFill.
- Software Update places the available-version action above release notes and preserves the last completed check time. Installation restarts Desktop, the tray and background service from the new bundle, preserves service preferences and explicit stops, and restores the previous components if relaunch fails.
- Permission status refreshes when the background service reconnects. iCloud status uses compact badges and omits zero pending changes.
- Chinese labels use natural punctuation and keep punctuation attached during wrapping and truncation. Device actions and protocol tags have consistent spacing.

## Distribution and validation

Stable and Beta desktop channels can upgrade earlier `0.1.4-beta.N` installations to `0.1.4`. The relay stable update feed also advances to this release. macOS packages are Developer ID signed and notarized, and app/relay update manifests are signed with Ed25519.

Authentication validation uses real Rust RVP/TLS/SPAKE2 connections, local relay carriers and an iOS simulator with encoded test video and recorded input. This does not establish physical-device, WAN or third-party RDP/ARD server acceptance. The mobile source is versioned `0.1.4` (5); this GitHub release does not submit or publish an iOS App Store build. CloudKit Production evidence remains scoped to the existing validation reports.

The Rust dependency stack was updated during the beta series. Upstream RSA audit findings and maintenance warnings remain documented in the [dependency report](https://github.com/backrunner/removent/blob/v0.1.4/docs/validation/dependency-ui-2026-10-11.md).
