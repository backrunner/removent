# 0.1.7 正式修复版发布前 review

日期：2026-10-22。检查范围为 `53ed907` 之后的全部待提交修改，以及从 `0.1.6` 正式版到 `0.1.7` 的发布说明与版本入口。

## Review 与修正

- 对照 crates.io `mdns-sd 0.21.5` 原始源码核对 vendor 内容、依赖锁定、workspace patch 与许可证。修改集中在缓存生命周期、接口归属、查询和回归夹具；解析器及上游 changelog 仅规范化原有行尾空白。
- 检查仅发布服务时的缓存过滤位置，保留名称冲突处理；浏览、主机名解析和明确启用 unsolicited 缓存的消费者继续工作。
- 检查 PTR/SRV/TXT/NSEC 独立过期、空键清理、稀疏容量回收，以及最后一个有效接口消失时才移除服务的通知。
- 补齐已知答案的接口隔离：查询只携带从该发送接口学到、剩余 TTL 足够的记录。新增测试检查实际编码/解析后的查询报文，并覆盖一个接口刷新后另一个接口接近过期的情况。临时移除接口过滤时，该测试失败；恢复修复后通过。
- 修正内存测试夹具，在创建 daemon 前释放临时端口，并断言 IPv4 socket 已初始化。
- 扩展运行上游集成测试。原版也复现未运行接口被计数、IPv4/IPv6 测试混用另一协议、异步 SRV 更新前已排队的旧事件等失败。夹具现在只计运行接口、隔离目标协议/接口，并严格要求新 SRV 到达及最终缓存中的主机名正确。大小写主机名测试也明确选择接口。
- 官网入口更新为 `0.1.7`，同步浏览器断言；下载失败回退测试继续检查其固定的历史版本链接。
- 正式说明包括内存和多网卡修复，以及已经进入 beta 的 Keychain 凭据记忆、登录启动和界面改进。没有加入新的协议版本或扩大平台承诺。

本地 review 未留下已确认而未解决的发布阻塞问题。远端 CI、跨平台 Relay 和签名公证发布仍由同一提交的工作流负责验收。
