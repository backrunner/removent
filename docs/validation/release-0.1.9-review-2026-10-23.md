# 0.1.9 发布审查

范围：Keychain 自动认证和连接表单编辑、用户登录自启管理、管理员安装的 LoginWindow 服务。候选来自 `48b2a43`，在独立工作区固定源码；审查期间另行写入的移动端改动不包含在本次桌面发布中。

## 审查修复

- 修复签名预检的 `codesign -R` 参数：内联要求必须以 `=` 开头，否则合法的正式安装包也会被当作不存在的要求文件而拒绝。新增真实 `csreq` 解析回归，并用已安装的 Developer ID 正式包验证同一要求和 Gatekeeper，均通过。开发包拒绝测试继续保留。
- 管理员 CLI 在读取用户设置或安装日志钩子之前识别系统服务命令，避免用户控制的 FIFO 阻塞及崩溃日志向用户路径写入。实际 CLI 集成测试使用 FIFO 配置文件验证命令仍可退出，且不创建诊断文件。
- 系统快照先验证 Ed25519 私钥和证书公钥匹配。错配或损坏的证书在创建快照内容前失败，避免把无法握手的身份发布为已安装服务。
- 修复 CLI 测试夹具的 macOS socket 竞态：接受非阻塞监听器的连接后显式恢复阻塞模式，再应用原有 3 秒读取超时；未放宽断言或超时。

## 验证

- 全工作区 Rust 测试 597 项通过、10 项忽略，严格 Clippy 通过。单独执行的真实 Keychain 合成条目往返和隔离 launchd 生命周期各 1 项通过，测试条目与临时服务已清理。
- 格式、布局、diff 空白、仓库 Python 和 shell 检查通过，Python 检查保留 1 项已有跳过。依赖 `block 0.1.6` 的既有 future-incompatibility 提示仍在。
- Swift 托盘 6 项、CloudKit 本地模型 5 项通过，托盘实际进程与合成 IPC 集成通过。此处没有进行真实 CloudKit 同步。
- 官网类型检查、静态构建、30 页中英翻译检查、8 项支持接口测试和 Worker 打包预检通过。
- Chromium/WebKit 最终 40 项全部通过。首次运行的 Chromium 侧栏滚动状态断言失败；保持源码和断言不变，单项重复 3 次与完整 40 项复验通过，保留该不稳定结果记录。
- 原生凭据和自启界面的前序验收见 [Keychain 记录](native-credentials-2026-10-22.md) 与 [自启记录](startup-management-2026-10-22.md)。

## 验收边界与发布门禁

按用户要求，没有进行真实注销或重启。系统服务的管理员安装、登录前画面与输入、进入用户会话后的交接仍未完成实机验收；FileVault preboot 解锁不在功能范围内。发布说明明确列出这一边界。

推送后仍须等待同一提交的完整 CI、Relay 工作流通过，才创建签名 `v0.1.9` tag。发布完成须下载公开 ZIP、DMG、三个 relay 包，检查校验和、更新清单签名、Developer ID、公证及 Stable 更新入口。
