## 准备 Windows

在 Windows 主机上启用远程桌面，并允许目标账户登录。Windows 版本与网络策略必须支持传入 RDP。确认 Mac 可以访问服务端。

## 添加连接

1. 选择**添加连接 → RDP**。
2. 输入主机名或 IP，默认端口为 `3389`。
3. 输入用户名、密码，以及环境要求的域。
4. 发起连接，等待中的连接可以取消。

Removent 使用 IronRDP 在应用内提供 TLS、NLA/CredSSP、图形、键盘和鼠标输入。连接对话框中的密码不会写入设置。

## 服务端证书

默认验证服务端证书。对于自签名服务端，请建立系统信任，或在核实主机后，明确允许该连接使用不受信任的证书。

## 当前范围

RDP 仅支持客户端，Removent 不提供 RDP 服务端。目前未实现 RDP 音频、剪贴板、文件重定向和自动重连。

连接失败时，请检查主机地址、Windows 远程桌面设置、账户权限、证书信任，以及两端之间的防火墙或 VPN。
