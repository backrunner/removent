Removent `0.1.10` fixes double-click recognition over the native Removent protocol and improves mouse, keyboard and scrolling reliability.

- Restore double and triple clicks on macOS hosts. Injected events now carry the click count and matching mouse-down/mouse-up event numbers, with independent click history for each remote session and the host's configured double-click interval.
- Preserve remote modifier flags for mouse clicks and scrolling. Modifier-key changes use native `FlagsChanged` events, and repeated key presses carry the correct autorepeat flag.
- Keep high-frequency pointer movement from consuming the input budget needed for clicks and typing. Excessive key/button transitions end the session and release held inputs instead of silently dropping a transition.
- Position the remote pointer before desktop scrolling, preserve fractional scroll deltas, and finish scroll gestures on focus loss, gesture cancellation or session teardown. Disconnect cleanup continues to release held keys and all three mouse buttons.

Update the **controlled Mac's app and background host service** to receive the double-click fix. Update both ends for the desktop scrolling improvements. These changes keep RVP protocol v1 and remain compatible with existing peers. Click timing is reconstructed on the host; severe network stalls that alter the interval between clicks remain a limitation.

Local validation includes native QUIC-to-AppKit event delivery, double-click counts, Shift-right-click, middle-button dragging, keyboard repeat, scroll phases, input flooding and disconnect cleanup. Cross-machine WAN jitter and physical iPhone/iPad gestures were not part of this validation.

The desktop app requires Apple Silicon and macOS 26 or later. Standalone relay packages support Linux x86_64, Linux ARM64 and macOS Universal. This stable release is available through Software Update; iOS follows its separate distribution process.
