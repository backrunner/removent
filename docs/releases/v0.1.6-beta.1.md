Removent `0.1.6-beta.1` is a beta release for remote desktop rendering and system audio fixes.

- Desktop viewers paint decoded frames within the visible image bounds. This fixes a black screen that affected both VNC and Removent connections even when frames were received and decoded correctly.
- A missing, delayed or ended system audio stream no longer closes an active Removent video stream after ten seconds. Video retains its startup deadline and closes promptly when its own stream ends.
- macOS system audio capture accepts both interleaved and planar 48 kHz stereo float PCM. Capture and Opus encoding share the same 10 ms frame size, preserving channel order and timestamps.
- Default device names respect the 63-byte settings limit, including computers with long hostnames. UTF-8 characters remain intact.

The desktop app requires Apple Silicon and macOS 26 or later. RVP remains protocol v1. Relay packages retain Linux x86_64 / ARM64 and macOS Universal support.

This GitHub prerelease does not upload or submit an iOS App Store build. The stable update channel remains on `0.1.5`.
