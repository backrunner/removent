Removent `0.1.3-beta.1` is a prerelease for testing the next update. RVP protocol remains v1. The desktop app requires Apple Silicon and macOS 13 or later; the standalone relay also supports Linux x86_64 / ARM64 and macOS Universal.

## Desktop and background service

- Independent discovery controls for Removent, VNC and RDP. VNC and RDP discovery is opt-in, limited to directly attached LANs, and confirms protocol handshakes without logging in.
- Discovered VNC and RDP devices open the appropriate connection form. Device rows, saved connections and the local Mac row share consistent spacing and truncate long names and addresses correctly.
- Explicitly stopping the daemon persists across desktop/tray reopening and login. Concurrent starts remain serialized; the tray and launchd recover unexpected daemon exits without overriding a deliberate stop.
- Improved tray localization/resource loading in installed bundles, independent service controls, and development-session lifecycle handling.
- Bounded update-request retries with clearer network error feedback. A beta installation can later update to a newer stable release.

## Relay and diagnostics

- Optional automatic installation of signed stable relay updates, disabled by default. Configure `[updates] enabled = true` and `check_interval_secs = 86400` in `server.toml`, then restart. Applying an update briefly interrupts relay connections.
- `removent-relay check-update` checks manually without installing. Downloads are checked against Ed25519 signatures and SHA-256 hashes; macOS also verifies Developer ID. Verified updates live in the relay state directory without granting write access to system binary directories.
- Relay, desktop, daemon and client CLI use local logs that rotate at 8 MiB with three backups. Crash reports are retained separately.
- One relay process per identity directory across configurations and transports.
- Cloudflare management moves to the existing deployment scripts and dashboard. Container images continue to update through deployment.

## Downloads and beta installation

- The website resolves the latest stable macOS installer and release notes directly from GitHub, with a fallback link when lookup fails.
- Beta artifacts retain their full version in filenames and bundle metadata. This GitHub prerelease does not replace the stable release or enter the automatic update feed.

Download the signed, notarized macOS DMG or ZIP from this release. To explicitly install the beta relay:

```sh
curl -fsSL https://raw.githubusercontent.com/backrunner/removent/v0.1.3-beta.1/scripts/install_relay.sh | sh -s -- --version v0.1.3-beta.1
```

Existing configuration and identities are preserved. Restart an existing relay after installing. Automatic update checks still follow the stable channel; future beta builds are installed manually. This prerelease does not claim new physical-device acceptance for lock-screen / LoginWindow support or Cloudflare public-network performance.
