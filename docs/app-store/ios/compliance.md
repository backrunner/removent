# iOS 隐私与合规记录

## 已审查的数据流

- SwiftUI 界面通过本地 Rust bridge 控制会话；移动依赖包含原生、VNC、RDP 和中继客户端，没有广告、分析、崩溃上传或内购 SDK。
- 偏好在应用自己的 UserDefaults，密码在 Keychain，连接与身份在应用容器。屏幕、输入和可选音频/文本剪贴板发送给用户选定的电脑。默认不传给 Alkinum。
- 主动开启 CloudKit 时，连接元数据进入用户私有数据库，密码和配对秘密不上传。支持页面在外部浏览器打开；提交表单会把用户输入发送给 Alkinum 的 OnFire。
- App Privacy 建议草案：不跟踪，不用于广告。应用功能数据与用户主动提交的外部网站支持资料分别审查；不能凭借隐私清单中的空数组认定完成 App Store 问卷。最终申报由发布者确认，未在 Connect 发布。

## Required Reason API

| 类别 | 原因 | 实际用途 |
| --- | --- | --- |
| UserDefaults | CA92.1 | 只读写应用自己的音频、剪贴板及发现设置 |
| FileTimestamp | C617.1 | Rust 文件元数据操作限定在应用容器的连接、身份和本地同步存储 |
| SystemBootTime | 35F9.1 | Swift 会话计时、Rust Instant、超时和音视频反馈中的应用内时间差 |

静态 Rust 库与第一方 Swift 代码进入同一应用可执行文件，由应用 bundle 中的 PrivacyInfo.xcprivacy 声明。未发现直接磁盘容量查询或系统活动键盘枚举。会话英文键盘是应用内输入视图，不是系统键盘扩展。还需核查候选二进制的导入符号和清单打包。

Apple 原因代码依据：[Required reason API](https://developer.apple.com/documentation/bundleresources/app-privacy-configuration/nsprivacyaccessedapitypes/nsprivacyaccessedapitype)。

## 加密出口

Rust 链接 rustls/aws-lc、SPAKE2 以及兼容协议加密实现。应用不是仅使用 Apple 系统 HTTPS 的情况。整理算法和最终二进制后，按 Apple 问卷判定，不自动添加 ITSAppUsesNonExemptEncryption=false。法国等地区的材料需求以及法律分类结论待发布者确认。

[Apple 出口合规](https://developer.apple.com/help/app-store-connect/manage-app-information/overview-of-export-compliance/)。

## 年龄、权利与地区

没有应用内社交、博彩、广告、内容商店或原生浏览器。远程电脑可以显示用户已有内容，审核说明应交代通用桌面镜像。年龄分级按当前问卷逐项回答，不预设 4+。品牌资源及依赖许可证分别核对；技术审查不等于法律许可或 Apple 审批。可售地区待确认。

## App Privacy 待确认填报矩阵

以下为数据流审查结果，不是已保存的 App Store Connect 答案。发布者须确认链接到外部支持网站的数据是否计入本应用披露范围，并复核最终构建及部署配置。

| 数据流 | 数据类型及目的 | 保留位置 | 填报边界 |
| --- | --- | --- | --- |
| 保存连接、设备证书、偏好 | 地址、连接名称、设备身份，用于连接功能 | 本机应用容器 | 无自动上传到 Alkinum；不应仅因本机存储就填为服务器收集 |
| 密码与配对凭据 | 认证信息，用于连接功能 | 本机钥匙串/身份存储 | 不参与可选 CloudKit 同步，不发送给支持系统 |
| 原生远程会话 | 所选电脑画面、键盘/指针输入，可选音频与文本剪贴板 | 用户选择的电脑与控制端，私有中继转发 | 用户主动发起的加密传输；Alkinum 没有集中录屏、广告或分析服务 |
| 可选 CloudKit | 已保存名称、地址、路由及主机身份，用于设备间同步 | 用户的 CloudKit 私有数据库 | 默认关闭；核对 Apple 对用户私有云数据的披露规则及生产权限 |
| 外部支持页面 | 邮箱、主题、正文、分类、语言，可选应用/系统/设备信息，用于客户支持 | Alkinum OnFire | 邮箱可能属于联系信息；正文可能属于其他用户内容；可选设备资料须按实际提交内容分类。需确认与身份关联以及披露范围 |
| 官网安全 | 请求 IP、Turnstile 验证和限流信息，用于防滥用 | Cloudflare/OnFire 基础设施 | 不用于广告追踪；服务商保留与处理需按生产设置复核 |

追踪、广告、出售数据、第三方分析 SDK：当前源代码与网站没有对应实现。最终“是否收集数据”、与身份关联及用途复选项仍需发布者确认，不生成未经确认的“不收集”结论。

## 年龄分级问卷工作底稿

| 项目 | 当前实现 | 待填报条件 |
| --- | --- | --- |
| 广告、内购、付费订阅 | 无 | 核对最终发行构建 |
| 应用内社交、公开用户内容、聊天 | 无；外部支持表单为私有客服沟通 | 不把支持工单当成公开社区 |
| 赌博、竞赛、模拟赌博、战利品箱 | 无 | 核对商店问卷对应选项 |
| 医疗、健康、暴力、色情或药物主题内容 | 没有随应用提供此类内容 | 远程电脑可能显示用户自己的内容，不据此保证远端内容分级 |
| 不受限制的网页访问与内容能力 | 没有内嵌通用浏览器；用户可控制远端电脑上的浏览器 | 按 Apple 对远程桌面能力的当前问卷说明确认，保留发布者决定 |
| 家长控制、年龄验证 | 没有专门的年龄控制功能 | 不宣称具备此能力 |

不要预填 4+ 或其他最终等级；由 App Store Connect 根据发布者确认的完整问卷计算。商店截图使用隔离文档内容，不包含私人或分级敏感内容。

## 已验证与尚未验证

模拟器检查和 unsigned iOS Release 编译已完成；应用包包含隐私清单、英文/中文局域网权限说明和开源许可证。`dist/app-store-ios/readiness.json` 记录真实验证范围和剩余条件。501 个依赖为保守解析闭包，包含构建及替代平台依赖；300 组许可证文本已归档，32 个包缺少根目录许可证文本须继续核对，并不代表最终运行时恰好包含 501 个包或已取得法律许可。
