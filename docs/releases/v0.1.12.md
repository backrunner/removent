Removent `0.1.12` adds automatic updates for idle user-session hosts and an independent recovery channel.

- Automatic installation defaults to on and can be disabled in Software Update. Existing opt-outs from automatic checks remain respected. Close the main window and finish connections to allow unattended installation.
- A signed background updater checks independently of the desktop and host. Installs preserve active connections, manual host-stop intent, device identity and existing permissions.
- Before replacement, the actual desktop must pass an isolated startup check. After replacement, the host must remain healthy for 60 seconds. Failed or interrupted installs restore the verified previous application; higher repair releases remain eligible.
- A separate pinned supervisor retains working updater copies and recovers if a new updater crashes. The update channel can continue operating when the desktop or host has a functional failure.
- Permission, signing, protocol and filesystem preflight run before stopping the host. Updates requiring new permissions or an administrator-owned application replacement wait for interactive handling.

The administrator-managed login-window host keeps its existing root-owned copy. General settings reports when that copy needs an administrator-approved update. Install this release using the current update flow before relying on its new recovery mechanism. RVP protocol v1 is unchanged.

Local acceptance covers real packaged desktop/host startup, signed fault fixtures, rollback and subsequent repair, process death with a missing application path, updater-worker fallback, supervisor restart and preservation of manual host stop. This is startup and recovery evidence, not a guarantee that every capture, audio or remote session path is free of bugs. The existing br-gateway service was preserved.

The desktop application requires Apple Silicon and macOS 26 or later. Standalone relay distribution is unchanged.
