Removent `0.1.7` fixes background-service memory growth and improves discovery when multiple network interfaces are active. It also brings the `0.1.7-beta.1` credential and installation improvements to the stable channel.

- The background service no longer caches unrelated mDNS responses while it only publishes sharing availability. Orphaned and expired discovery records are reclaimed, and sparse cache tables release retained peak capacity.
- Discovery records keep separate lifetimes for each network interface. Disconnecting one interface preserves services still reachable through another; cache-flush updates and known-answer query suppression stay on the correct link.
- On macOS, native system-account and independent-password connections can remember successful credentials in Keychain. Credentials are scoped to the controller identity, verified host certificate, and authentication method, and stay outside connection files and iCloud sync. Pairing codes and one-time passwords are never remembered.
- New installations enable the background service at user login. Explicit login-off and manual-stop choices survive updates and reinstallations; the command-line installer supports `--no-login`.
- Native connection timeouts give clearer sharing and UDP-port guidance. Software Update and iCloud sync use more compact controls and clearer status text.

The desktop app requires Apple Silicon and macOS 26 or later. RVP remains protocol v1. Standalone relay packages support Linux x86_64, Linux ARM64, and macOS Universal.

This is a stable GitHub release. Existing Stable-channel installations can receive it through Software Update. The iOS App Store release follows its separate distribution process.
