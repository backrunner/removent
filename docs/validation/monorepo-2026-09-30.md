# Monorepo refactor validation — 2026-09-30

This refactor reorganizes the existing working tree, including its uncommitted
mobile and CloudKit work. It preserves executable names, data directories,
protocol formats and public Rust interfaces. Git's index was not changed.

## Organization

- Application targets moved to `apps/`; reusable Rust and Swift code moved to `packages/`.
- The relay's reusable transport library is now `packages/relay-transport`; the
  `removent-relay` workspace dependency aliases that library while the existing
  `removent-relay` executable package stays in `apps/relay`.
- Mobile and the macOS CloudKit helper compile the same Swift source under
  `packages/apple-cloud-sync`. Native Xcode projects are generated from their
  relocated XcodeGen specifications and ignored by Git.
- Deployment templates moved to `infra/`. Scripts and documentation are grouped
  by responsibility. Public standalone installer URLs and `scripts/dev.sh` remain stable.
- Cargo, native projects, Docker build contexts, CI paths, release signing source
  pointers, public website edit links, local documentation links and ignore rules
  were updated together.
- `make` provides common check/build/test entry points. `scripts/check_layout.py`
  enforces workspace membership, package dependency direction, source size budgets
  and agreement between desktop/relay release verification public keys.

The connection dialog and viewer were split into form/lifecycle, input, rendering
and test modules. Cloud sync separates merge policy and durable storage. CLI
commands separate dispatch, daemon management and ping. The tray's 676-line
controller now uses a small state/lifecycle class and six extensions for menu,
events, alerts, actions, service management and login items; the largest is 208 lines.
The 1,450-line session loopback suite now uses eight behavior-specific test modules
with one shared harness. Other large test blocks moved out of production files.
