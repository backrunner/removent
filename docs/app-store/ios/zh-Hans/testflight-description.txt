通过 iPhone 或 iPad 连接你的电脑。Removent 是由 Alkinum 提供的远程桌面控制端。

选择连接方式
使用原生 Removent 连接运行桌面主机的 Mac，连接兼容的 VNC 或 Apple Remote Desktop 服务器，或通过 RDP 访问已配置远程桌面的 Windows 电脑。保存常用连接，也可以发现局域网中的兼容电脑。

操作远程屏幕
查看电脑画面，发送触控、鼠标和键盘输入。会话使用直接发送字符的英文键盘，也支持硬件键盘。横屏会话在保持画面比例的同时铺满屏幕，被裁切的边缘可以通过平移查看。悬浮控件闲置后隐藏，需要时轻触画面即可唤回。

原生连接
原生 Removent 会话支持配对、证书信任检查、可选的文本剪贴板传输和远程音频播放。需要在局域网之外使用原生连接时，可以配置自己的私有中继。中继访问权限不能替代电脑认证。

保存与同步
凭据保存在设备钥匙串中。你可以选择通过同一 iCloud 账户，与其他 Removent 设备同步已保存的连接信息。密码、配对秘密和证书验证例外保留在各自设备上。

连接前须知
iOS 应用仅作为控制端，不能把 iPhone 或 iPad 作为被控主机。你需要一台可访问的电脑，并获准操作它。原生 Mac 主机要求 macOS 26 或更新版本，并需要屏幕和输入权限。VNC 与 RDP 需要兼容且已配置的服务器，采用各自的认证和加密机制。本版本 RDP 不提供音频、剪贴板或文件重定向，应用不包含文件传输功能。

应用免费，没有内购。会话期间请保持应用在前台。局域网权限用于发现和连接附近电脑，iCloud 同步需要主动开启。
