# Install the current macOS checkout

Run `make install-local` to build and install Desktop, removentd and the SwiftUI menu bar app together at `/Applications/Removent.app`. This refreshes the running service and launches the installed Desktop, preserving data and existing login preferences. Finish active remote sessions first.

For an already built bundle, `python3 scripts/install_local.py --no-build` verifies its source fingerprint before installation. It refuses stale bundles, including local source edits that have not been rebuilt. `--destination ~/Applications/Removent.app` selects a user-owned installation directory.

The tray footer shows the release and source revision. `Contents/Resources/build-info.json` records the build timestamp and source fingerprint. A `-local` revision includes uncommitted changes. The installer preserves the installed app and RemoventHost signing certificates independently; Screen Recording and device-control authorization can be bound to different certificates. For a first installation it prefers a single available Developer ID identity, falling back to Apple Development. Set `REMOVENT_LOCAL_SIGNING_IDENTITY` to choose a local certificate explicitly, or `REMOVENT_LOCAL_HOST_SIGNING_IDENTITY` to choose the host certificate separately. A deliberate certificate change may require authorizing the new signature, even when System Settings still shows the old entry enabled; restarting the service cannot repair a signature mismatch. If the installed certificate is unavailable, the installer stops instead of silently changing it. Without a certificate on a first installation, packaging falls back to ad-hoc signing; permissions may then need granting again after a rebuild. Release signing remains separate.

The first user-session daemon launch with sharing enabled requests Screen Recording and Accessibility asynchronously. The daemon ships inside `Contents/Helpers/RemoventHost.app` with the stable identifier `com.alkinum.removent.host`; the adjacent `Contents/MacOS/removentd` is a relative symlink. Accessibility identifies this component as RemoventHost on current macOS, while some versions may use its localized display name, Removent Host (Removent 屏幕共享 in Chinese). macOS may attribute Screen Recording to the containing Removent app. Request markers in `permissions/host-v1/` prevent repeated prompts after denial or service recovery. The login-window agent never requests interactive permissions. Both Desktop and the tray display removentd's grants and send permission requests to it. Each tray permission row can request again; its options also open System Settings and restart the service when macOS requires it.

For the first local CloudKit installation, set `REMOVENT_CLOUDKIT_PROFILE` to a Developer ID profile for `com.alkinum.removent.sync` associated with the existing `iCloud.com.alkinum.removent` container. Subsequent local updates preserve the installed helper's profile and verify that it authorizes the actual signing certificate. The default environment is Production; selecting Development requires a profile authorizing that environment. Keep profile files outside the repository.

Left-click the brand icon to open the SwiftUI panel. Right-click for the command menu. Closing Desktop or quitting the tray leaves the background service running; an explicit service stop remains respected.
