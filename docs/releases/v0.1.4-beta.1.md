Removent `0.1.4-beta.1` improves connection recovery, device navigation and Chinese typography, and upgrades the Rust dependency stack. RVP protocol remains v1. The desktop app requires Apple Silicon and macOS 26 or later; the standalone relay supports Linux x86_64 / ARM64 and macOS Universal on macOS 13 or later.

## Connection recovery

- Desktop and mobile share bounded automatic recovery for Removent, VNC and RDP. Temporary interruptions retain the viewer and last picture; input and audio pause while reconnecting.
- On Apple platforms, an offline network shows a clear status overlay. Recovery resumes automatically when the OS reports an available route, without consuming retries while offline.
- Intentional disconnects stop recovery. Reconnects preserve the authenticated host identity and rotating resume token; one-time invitations resolve only once, and stale session events are rejected.
- Corrected VNC canvas sizing and mouse mapping, including the title-bar offset. A server TCP close now enters recovery instead of being treated as a successful session end.

## Device navigation and typography

- Saved connections and LAN discovery have separate sections, counts and empty states. Single-digit counts use square badges; row content keeps consistent alignment across selection and hover.
- Connection and edit actions sit beside the device heading. Removal is available in the more menu, and heading/subtitle spacing is tighter.
- Protocol and local-device status use capsule tags. Chinese information no longer uses dot separators, and the convention is documented for development.
- Chinese wrapping and truncation keep punctuation with its text across measurement and rendering. LAN empty-state icons are clearer, and the disabled state offers a quick action to enable Removent, VNC and RDP discovery.
- Changing a connection destination cannot reuse credentials scoped to the previous destination. Discovery settings remain unchanged if saving fails, allowing a retry.

## Dependency and platform maintenance

- Upgraded Rust workspace dependencies and adapted the GPUI, ScreenCaptureKit, audio, discovery, certificate and cryptographic APIs. The development toolchain requirement is now Rust 1.92 or later.
- Updated Apple bridge packages while preserving iOS SDK and platform-symbol compatibility. Restored system font and Linux platform features, and supplied the Swift concurrency runtime link path on macOS.
- Made tray duplicate-start integration checks wait for actual readiness instead of a fixed startup delay.
- One direct dependency upgrade, ed25519-dalek 3, remains blocked by incompatible upstream constraints. The audit still reports an upstream RSA vulnerability without an available fixed version and dependency maintenance warnings. See the [dependency validation report](https://github.com/backrunner/removent/blob/v0.1.4-beta.1/docs/validation/dependency-ui-2026-10-11.md).

Local validation includes workspace tests, strict Clippy, native desktop presentation and loopback VNC recovery, iOS simulator unit and offline UI tests, and development packaging. It does not establish physical-device network switching, WAN or live third-party RDP/ARD acceptance. Previous CloudKit Production evidence remains scoped to the [existing validation report](https://github.com/backrunner/removent/blob/v0.1.4-beta.1/docs/validation/cloudkit-production-2026-10-09.md).

This is a GitHub prerelease. Select the Beta update channel or download this beta explicitly. The latest stable release remains `0.1.3`; relay automatic updates continue to follow stable releases.
