# Removent 需求文档

版本：v1.0（2026-08-22） · 状态：已评审待实现 · 上游文档：[README](./README.md)

## 1. 项目概述

Removent 是一个**客户端、服务端一体**的远程桌面应用，对标 NoMachine / RustDesk 的核心使用体验，
使用 Rust + GPUI 全自研实现。首发仅支持 macOS（≥13.0，arm64 优先）。

### 1.1 设计目标（按优先级）

1. **流畅优先**：局域网内 60fps@1440p 稳定输出，运动到显示延迟（motion-to-photon）≤80ms。
2. **低带宽可用**：1 Mbps 下文本仍可阅读（HEVC），码率自适应范围 1–32 Mbps。
3. **音频低延迟透传**：被控端系统声音端到端 ≤60ms，音画不同步 ≤±40ms；后续支持双向语音。
4. **能力对齐主流产品**：共享剪贴板、文件传输、多显示器、免打扰被控等，见 §5 对标矩阵。
5. **零配置连接**：mDNS 自动发现 + 一次配对永久信任，日常连接 ≤2 次点击。
6. **安全默认**：全程 TLS 加密、会话准入确认、指纹可视化校验。仅限局域网，不提供任何公网中继/穿透。

### 1.2 用户角色

| 角色 | 说明 |
| --- | --- |
| 控制端用户 | 在自己设备上查看并控制远端机器的人 |
| 被控端用户 | 机器被人连接的机主，需要准入控制与隐私保护 |

两种角色由同一二进制承担，可同时开启（本机既被控又控他机）。

## 2. 核心用户场景

- **S1 日常运维**：Mac mini 放在书房无显示器，从 MacBook 连上去当"远程主机"用，打字延迟感知不到。
- **S2 协助家人**：家人 Mac 出问题，我方在局域网内发起连接，对方点一次"允许"，我接管排障。
- **S3 媒体场景**：客厅 Mac 在放音乐/视频，我在卧室通过远程会话听声音、切歌，声音不卡顿不延迟明显。
- **S4 文件搬运**：两台机器间拖拽/复制粘贴传文件，无需 U 盘或 AirDrop。
- **S5 免屏值守**：Mac 无头运行，开机自动进入被控服务，随时可连。

## 4. 非功能需求

| 编号 | 类别 | 指标 |
| --- | --- | --- |
| NFR-01 | 延迟 | 局域网 motion-to-photon ≤80ms（典型 ≤55ms）；预算分解见 milestones.md 附录 A |
| NFR-02 | 音频延迟 | 系统声端到端 ≤60ms（典型 ≤40ms）；音画偏差 ≤±40ms |
| NFR-03 | 帧率 | M 系芯片 1440p60 稳定；4K ≥30fps；静态画面零编码负载 |
| NFR-04 | 带宽 | 自适应 1–32 Mbps；1 Mbps 下 1080p 文本可辨（HEVC）；空闲 DTX 后 <100 kbps |
| NFR-05 | CPU | 被控端会话中 ≤15% 单核（含采集+硬编+网络）；空闲被控 <2%；控制端解码 ≤10% 单核 @1440p60（硬解） |
| NFR-06 | 可靠性 | 会话崩溃不拖垮宿主进程（媒体管线 panic-isolated）；断线自动重连；传输层丢包由 QUIC 恢复 |
| NFR-07 | 安全 | 全流量 TLS 1.3；身份密钥 Ed25519 本地生成不出机；配对用 SPAKE2 抗 PIN 爆破；会话准入默认开启 |
| NFR-08 | 隐私 | 无遥测上报；剪贴板内容仅内存流转不落盘；日志不含剪贴板正文与画面数据 |
| NFR-09 | 兼容 | macOS ≥13.0；Apple Silicon 全系支持，Intel 尽力支持（软编回退路径保留） |
| NFR-10 | 可维护 | workspace 分 crate 编译隔离；协议字段全部显式编号；关键管线有 tracing span 与统计指标 |

## 6. 权限矩阵（macOS TCC）

| 权限 | 用途 | 申请时机 | 缺失后果 | 对应需求 |
| --- | --- | --- | --- | --- |
| 屏幕录制（Screen & System Audio Recording） | SCK 采集屏幕+系统声 | 首次开启"允许被控" | 无法被控（控制不受影响） | FR-10/20 |
| 辅助功能（Accessibility） | CGEvent 注入键鼠 | 首次被接受一次控制会话 | 只能看不能控 | FR-30/31 |
| 本地网络（Local Network，macOS 15+） | 收发 mDNS 与 QUIC 广播域流量 | 首次启动联网功能 | 发现不可用，可手动 IP 兜底 | FR-01 |
| 通知（可选） | 被控端来连提醒（后台时） | 用户主动开启 | 仅弹窗改菜单栏角标提醒 | FR-51 |

说明：
- 屏幕录制为纯 TCC 门禁，无 entitlement 可绕过；分发需 Info.plist 带 `NSScreenCaptureUsageDescription`。
- macOS 15+ 后台读取其他应用剪贴板可能触发粘贴板隐私提示，客户端在窗口聚焦时才拉取远端写入，规避骚扰（详见 architecture.md §7.3）。

## 7. 明确不做（Out of Scope）

- 公网可达性：无中继服务器、无 NAT 穿透、无配对码连接。产品定位就是局域网工具。
- 多用户并发会话（一台被控机同时被多人控制）：v1 单会话，后来者提示占用并可请求接管的交互放入 Backlog。
- Windows/Linux/macOS 之外的客户端形态（移动端、Web）。
- 远程打印、白板注释、VPN 式端口转发。
