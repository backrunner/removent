Removent `0.1.3-beta.3` updates the desktop app and background service. RVP protocol remains v1. The desktop app requires Apple Silicon and macOS 26 or later; the standalone relay supports Linux x86_64 / ARM64 and macOS Universal.

## Desktop and background service

- Hosting permission status and requests now come from the background host that performs capture and input control. First-launch requests are recorded to avoid repeated prompts after denial or service recovery.
- The host ships in a dedicated RemoventHost app bundle. When upgrading from an older host identity, macOS may require granting Screen Recording and device-control access to the new signature. Desktop and tray expose the host status and permission actions.
- The menu bar opens a branded SwiftUI panel with service status, permission actions, login preferences and an Options menu. Device selection, switches and light/dark theme feedback are refined.
- Corrected VNC mouse coordinates when the viewer title bar is present.
- Cloud sync publishes persisted state immediately at startup and recovers its helper without creating duplicate owners. Helper lifecycle checks do not establish real Mac/iPhone cloud-sync acceptance.

## Packaging and maintenance

- Local installation verifies the source fingerprint, preserves app and host signing identities independently, retains the installed CloudKit profile, replaces the desktop/service/tray together, and preserves existing data and login preferences.
- CloudKit packaging accepts Apple's iCloud service authorization wildcard while claiming only CloudKit, and verifies that the actual signing certificate is included in the profile. Desktop sync uses the existing mobile container.
- Standalone release verification loads the CloudKit validation module directly from the repository, avoiding caller-dependent import failures after notarization.
- Packaging stages a complete bundle before replacing the previous build. Login-window installation preserves the host bundle identity.
- Expanded permission, startup, theme, signing and lifecycle regression coverage, and restored compatibility with the current Rust toolchain and repository layout checks.

This is a GitHub prerelease and does not replace the latest stable release. Select the Beta update channel or download the beta explicitly. Relay automatic updates continue to follow stable releases. This prerelease does not claim new physical-device acceptance for CloudKit, lock-screen / LoginWindow support, or Cloudflare public-network performance.
