# Keychain 自动连接与凭据编辑

日期：2026-10-22。范围：macOS 桌面端，工作区源码和隔离配置的开发构建。

## 行为

- 已保存的系统账户、访问口令按本机身份、目标主机证书和认证方式匹配，直接交给认证握手，不发送凭据输入弹窗事件。
- 原生连接的编辑表单后台读取已存凭据，密码默认隐藏。保存或连接时提交修改，关闭存储开关并保存可删除相应条目。单纯关闭表单不保存。
- 编辑地址、端口、协议、中继路由或主机身份后不携带旧凭据；保存时再次核验身份。原生主机凭据不混入中继 token、书签或同步数据。
- 自动认证失败显示进入编辑表单的提示；连接失败不覆盖凭据。自动复用成功也不重写 Keychain，避免覆盖连接期间的编辑。
- 无已存凭据、凭据无法解码或 Keychain 读取失败时仍可手动认证。OTP、配对码和新的配对邀请不会复用旧凭据。

## 验证

- 桌面常规测试 124 项通过，4 项忽略；覆盖免弹窗认证、取消读取、无可用凭据、认证方式隔离、编辑校验、目标变化、最低窗口尺寸下深浅色布局和键盘焦点。
- 单独运行真实 Keychain 合成测试通过：系统账户和访问口令读取、修改、下次自动提交、目标变更拒绝保存及删除。测试条目已清理。
- `cargo check -p removent-app --locked`、桌面构建、严格 Clippy、工作区格式、布局与 diff 检查通过。依赖 `block` 仍有既有 future-incompatibility 提示。
- 独立应用和数据目录连接本地 synthetic RVP 主机，实际完成首次勾选存储、断开后直接重连、应用重启后直接重连、编辑错误口令后显示编辑提示、修正口令后从表单直接连接，以及移除凭据后恢复空白认证输入的流程。
- 实际窗口检查了深浅色凭据编辑表单、密码遮蔽、保存/连接操作和失败提示。开发应用和合成主机已退出，合成凭据已从 Keychain 移除。

系统账户凭据采用合成值验证存储与提交，没有使用用户真实系统密码完成远端系统账户登录。本次没有安装或发布新版本。
