Removent `0.1.7-beta.1` adds Keychain credential memory for native connections and enables background-service login startup on new installations.

- On macOS, system-account and independent-password authentication now offer **Remember credentials in Keychain**. Successful connections save the credentials; later authentication prompts fill them in for review. Turning the option off and connecting successfully removes the stored credentials. Cancelled or failed connections leave previous credentials intact.
- Credentials are separated by controller identity, host certificate and authentication method. Usernames and passwords stay in Keychain, outside connection files and iCloud sync. Temporary pairing codes and one-time passwords are never remembered.
- Local installation, the command-line installer, and the first launch after DMG or drag-and-drop installation enable `removentd` startup at user login by default. Later explicit login-off and manual-stop choices survive reinstallations and updates. The command-line installer provides `--no-login` for installation without starting the service.
- Native QUIC connection timeouts now direct users to check Removent sharing and the host's UDP port. Password authentication uses the authentication progress label instead of the pairing-PIN label.
- Software Update keeps its channel selector beside the description, and iCloud sync uses a compact primary action with clearer status and last-sync time.

Credential saving, hidden-password refill and deletion were verified with a synthetic native host and the real macOS Keychain. Login startup defaults, explicit opt-out and manual-stop preservation were verified with launchd and the installed CLI. Login startup refers to the user session; it does not unlock FileVault or provide a pre-login system service.

The desktop app requires Apple Silicon and macOS 26 or later. RVP remains protocol v1. Relay packages retain Linux x86_64 / ARM64 and macOS Universal support.

This is a GitHub prerelease and does not submit an iOS App Store build. Stable remains on `0.1.6`; select **Beta** in Software Update to receive this release.
