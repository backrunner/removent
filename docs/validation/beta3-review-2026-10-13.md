# 0.1.4-beta.3 发布前审查

本次审查覆盖工作区全部待提交文件：桌面设置与认证、更新状态、广播发现和连接去重、移动端、官网支持接口，以及 iOS 商店材料准备工具。发布目标为桌面 GitHub prerelease `v0.1.4-beta.3`，Stable 保持 `v0.1.3`。

## 审查结果与修正

- 访问口令采用未保存草稿，合法口令保存成功后才切换后台认证方式；离开设置恢复已保存值。OTP 的二维码和密钥默认隐藏，离开页面后重新隐藏，使用本地生成的标准绑定 URI。
- 发现入口仅使用 Bonjour/mDNS，删除桌面和移动端的子网端口扫描。列表去重比较协议、端口和广播提供的主机别名，不合并凭据或配对信任，也不合并 relay 连接。
- 更新检查时间记录已完成的检查，忙碌时跳过的检查不修改历史；只有手动检查显示无更新提示。自动发现的新版本继续显示下载操作。
- 官网支持入口限制请求来源、输入长度和请求体大小；产品与工单类型由服务端决定，密钥不返回浏览器。外部写入结果不确定时不自动重试。
- 拆分超过仓库 1000 行上限的桌面测试文件；CI 补充支持接口单元测试和 Worker 打包预检。
- 广播测试原先使用 TCP listener，受到本机 LocalStack 自动探测干扰。通过已接受连接的端点和 `lsof` 确认发起进程为 LocalStack PID 67375。改用绑定但不监听的 TCP socket，验证服务不可连接时广播仍能解析，测试不依赖其他本机进程是否连接端口。

## 公开发布验收

上述本机结果不是远端发布完成证明。提交推送后还须确认同一 SHA 的 CI 和 Relay 全部通过，再创建不可变 beta tag，并确认 Release 工作流完成 Developer ID 签名、Apple 公证和发布。公开 ZIP、DMG、校验和、更新签名及三个平台 relay 资产需再次下载验证。实际自动更新中的桌面、托盘、后台进程替换与权限状态以安装后的运行证据为准。
