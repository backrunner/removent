Removent `0.1.0-beta.4`，面向 **Apple Silicon Mac、macOS 13 及以上**。

Removent `0.1.0-beta.4` for **Apple Silicon Macs running macOS 13 or later**.

### 新增 / Added

- 可开关的左上角半透明性能面板，默认隐藏。将鼠标移至窗口顶边，点击工具栏仪表图标，或按 **Ctrl+Cmd+I** 查看分辨率、显示帧率和会话时长；VNC 另提供接收速率、像素处理耗时、输入排队及发送耗时。小窗口中可滚动查看完整信息。
- Optional translucent performance panel at the upper left. Use the toolbar's gauge button or **Ctrl+Cmd+I** to view resolution, display rate, session duration, and VNC receive, processing, and input queue measurements.
- 独立于主窗口和菜单栏的后台共享服务，以及分别控制服务和菜单栏应用的登录启动选项。CLI 新增服务启停、重启、登录启动和权限设置命令。
- Independent background hosting with separate server and menu bar login options, plus CLI service and permission controls.
- 本地滚动日志、连接阶段与超时诊断、受限大小的崩溃报告，以及设置页的日志目录入口。
- Rotating local logs, connection-stage diagnostics, bounded crash reports, and an Open Logs Folder action in Settings.

### 改进 / Changed

- VNC 输入发送与画面处理独立调度。扩大短时输入缓冲，仅合并相邻且按键状态相同的鼠标移动，保留按键、点击、滚动和释放顺序；高分辨率像素直接写入帧缓冲区，减少临时内存和逐像素转换开销。
- VNC input runs independently of framebuffer work. A larger transient queue preserves keys, clicks, scrolls, and releases while merging consecutive pointer moves with the same button state. Direct BGRA reads reduce high-resolution pixel processing overhead.
- 调整设置、设备列表、连接弹窗和按钮样式，改善明暗主题对比度、紧凑窗口布局、键盘焦点、连接进度与取消／重试体验。
- Refined settings, device lists, connection dialogs, and buttons, including theme contrast, compact layouts, keyboard focus, connection progress, cancellation, and retry behavior.
- 安装器检查后台服务是否仍在运行；更新时协调后台进程，并验证 DMG 的 Finder 布局和 Retina 背景。
- Installation checks for a running background service; updates coordinate background processes, and packaging verifies Finder layout and Retina artwork.

### 修复 / Fixed

- macOS 屏幕共享同时提供多种认证方式时优先选择兼容的 Apple type-30，并为握手各阶段提供明确超时与错误信息。
- Prefer compatible Apple type-30 authentication when macOS Screen Sharing offers multiple methods, with explicit handshake-stage timeouts and errors.
- 避免画面更新持续占用界面事件循环；静止画面下性能面板仍定期更新，显示正确的零帧率。
- Yield UI time between frame updates and refresh diagnostics independently, including zero frame rates on idle desktops.
- 面板内的点击和滚动保持本地操作；远端拖拽在面板上结束时仍释放鼠标。修复本地快捷键释放与远端已按下按键的边界情况。
- Keep panel clicks and scrolling local, preserve remote drag releases over the panel, and handle local shortcut key releases without leaving remote keys held.

### 安装与兼容性 / Installation and compatibility

下载 DMG，打开后双击 Removent 并选择「安装并打开」，或拖入 Applications。已有用户也可在应用中检查更新。

Open the DMG and double-click Removent to **Install and Open**, or drag it to Applications. Existing users can also check for updates in the app.

- 协议版本仍为 **RVP 1**，本次未修改网络消息格式。
- The native protocol remains **RVP 1**, with no wire-format changes in this release.
- VNC 仍使用远端原生分辨率和 Raw 画面传输；实际带宽与远端处理能力仍会影响流畅度。输入发送耗时仅衡量本地排队至写入连接，不代表远端响应时间。
- VNC still transfers raw pixels at the remote resolution. Bandwidth and server processing affect responsiveness; input send time measures local queuing through socket write, excluding the remote response.
- 后台共享需要已登录的 macOS 图形会话及对应进程的隐私权限；不支持 FileVault 预启动解锁、未登录状态或睡眠中的远程控制。
- Background hosting requires a logged-in graphical session and the host process's privacy permissions; it does not provide FileVault preboot, logged-out, or sleeping-host control.
