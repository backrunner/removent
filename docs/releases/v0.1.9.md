Removent `0.1.9` connects with remembered Keychain credentials automatically and adds background-service startup management to Settings → General.

- Native system-account and password connections reuse credentials saved for the same controller identity, verified host certificate and authentication method. Edit or remove them in the connection form. Failed authentication directs you to that form without overwriting the saved credential.
- Manage startup after user login from the main settings window. New installations enable it by default; disabling startup leaves the current service running, and explicit disable or stop choices survive reopening and updates.
- Set up remote access at the macOS login window with administrator authorization. Settings shows its separate enabled state, approved devices and update status. Signed installations offer setup by default; cancelling setup leaves a visible action without repeated prompts on every launch.
- The login-window host uses a protected copy of signed code, device identity and approved video/input grants. Installation verifies identity consistency, excludes app passwords and OTP secrets, and restores the previous installation if publication fails. Empty approval lists admit no devices.
- Add `daemon system-status`, `system-enable`, `system-update` and `system-disable` to the packaged CLI. Administrator commands avoid user-controlled diagnostic files and settings reads outside the bounded installation snapshot.

The new login-window installation and management paths have automated coverage. Actual logout/restart, login-window video/input and transition back to a user session have not yet completed physical-device acceptance. FileVault preboot unlock is outside this feature; a macOS login window is required.

The desktop app requires Apple Silicon and macOS 26 or later. RVP remains protocol v1. Standalone relay packages support Linux x86_64, Linux ARM64 and macOS Universal. This stable release is available through Software Update; iOS follows its separate distribution process.
