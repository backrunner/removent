## 托管所需权限

| 权限 | 用途 |
| --- | --- |
| 屏幕录制 | 捕获被控端显示器画面 |
| 辅助功能 | 注入远程键盘和鼠标输入 |
| 本地网络（macOS 请求时） | 发现和连接局域网设备 |

打开**系统设置 → 隐私与安全性**检查授权。控制端仅查看另一台设备时，不需要为此授予屏幕捕获权限。

## 设置后台进程

在 Removent 菜单栏应用中使用**设置屏幕共享权限…**。此操作由实际负责捕获和输入的 daemon 请求权限。

授权后选择**重启后台服务**，再检查权限状态。仅给主应用授权，不代表后台 daemon 已获得权限。

## 从终端检查

安装包包含 CLI：

```sh
REMOVENT_CLI=/Applications/Removent.app/Contents/MacOS/removent-cli
"$REMOVENT_CLI" daemon permissions
"$REMOVENT_CLI" daemon status
```

如果安装在 `~/Applications`，请使用该目录下对应的路径。

## 黑屏或无法输入

无法捕获画面时检查屏幕录制；可以看见画面但不能控制时检查辅助功能。修改权限后重启后台服务。

自动启动的后台进程不会弹出授权对话框。依赖[无人值守托管](/docs/hosting)前，请先交互式完成设置。

## 登录与睡眠

隐私授权不会解锁 FileVault、登录已退出的账户或唤醒睡眠中的 Mac。当前原生主机需要已登录的图形用户会话。
