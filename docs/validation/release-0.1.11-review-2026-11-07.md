# 0.1.11 发布审查

范围：原生视频表面、显示节奏与实际呈现统计，host 编码线程隔离，音频传输、抖动恢复和设备时钟播放，以及上一提交中的远程粘贴同步。协议保持 v1。详细性能证据见[实现和验证记录](game-streaming-implementation-2026-11-07.md)。

## 审查修复

发现 H.264/HEVC 解码器信任外部宽高，未检查参数集声明的尺寸；原生表面绕过了 CPU 图像长度检查，且等面积的错误宽高也能绕过该检查。新增 318×242 码流配合 242×318 声明的回归，先确认旧代码失败，再检查格式描述和实际输出表面的尺寸。修复后 H.264/HEVC 原生和 CPU 路径回归均通过，完整编解码库 17 项测试通过。

审查还覆盖了像素缓冲与 Metal 纹理持有期、音频回调与 FFI 句柄生命周期、队列上限、重连清理、线程退出及更新服务隔离。保留 vendored GPUI Apple 后端的 Apache-2.0 许可证和补丁说明。

## 验证与发布边界

本轮版本变更和尺寸修复后的本地检查：

- `cargo test --locked --workspace -- --test-threads=1`：632 项通过，12 项需要外部环境的测试默认忽略，0 失败。
- `cargo clippy --locked --workspace --all-targets -- -D warnings`、Rust 格式、diff 空白及 `scripts/check.sh` 全部通过。仓库脚本执行 94 项 Python 测试，含 1 项既有跳过；保留既有 `block 0.1.6` future-incompatibility 提示。
- Swift 托盘 6 项、CloudKit helper 5 项单元测试及托盘进程集成测试通过；更新清单签名自检和安装器类型检查通过。
- 独立运行更新生命周期验收 1 项通过，覆盖真实托盘、CLI 和 launchd 的替换、显式回滚、旧托盘刷新、手动停止和登录偏好保留。daemon 为隔离测试程序，不能替代完整更新包和真实媒体 host 验收。
- iOS Debug 模拟器和真机目标未签名构建均通过，未执行真机安装或运行测试。
- 更新测试结束后，本地原有 app、host、同步 helper 和托盘进程保持原 PID，没有替换现有安装。

版本统一为 0.1.11，Cargo.lock 的 14 个工作区包和 iOS 元数据同步更新。先前 `2026-11-07-local-validation-final.json` 是版本变更和本次尺寸修复之前的历史快照，不代表最终发布源码。

正式发布要求同一提交的 CI 和 Relay 工作流完整通过，再由 Release 工作流构建、签名、公证和发布。发布后还须从公开地址下载全部资产，验证哈希、更新清单签名、版本、公证、Gatekeeper 和构建来源。

先前双机动态实测尚未达到稳定 60 FPS，最终音频调整只完成本地验证，不能据此宣布游戏级稳定性或声学、输入到显示延迟验收通过。本轮保留 br-gateway 现有远端服务，不执行远端切换、安装或重启。

后台 host 无人值守更新的现状、缺口及实现边界见[独立审查](host-unattended-update-audit-2026-11-07.md)。本版本没有启用自动安装策略。
