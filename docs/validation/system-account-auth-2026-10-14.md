# 系统账户默认认证验证

日期：2026-10-14。环境：本机 macOS，隔离数据目录，未替换已安装应用。

## 行为

- 新配置及缺失认证配置默认使用系统账户。显式保存的配对码、访问口令、OTP 和无认证配置保持原值。
- macOS 通过 Open Directory 验证运行共享服务的非 root 系统账户，不接受其他用户的账户。系统登录密码不会持久化，凭据 Debug 输出脱敏。
- 控制端须先确认或固定主机证书，再通过 TLS 发送凭据。新的协议能力位防止旧客户端降级；握手校验双方随机数。
- 桌面及 iOS 控制端显示用户名与隐藏密码输入框。桌面设置使用下拉菜单选择认证方式。
- 原有短时恢复窗口保持有效，缺少认证策略记录的恢复令牌不再获准恢复。系统密码改变在下一次完整认证时检查。
