Removent `0.1.6-beta.2` adds concurrent desktop sessions across devices and protocols.

- Each machine can have one active session per protocol: Removent, VNC (including Apple Remote Desktop), or RDP. Different machines or protocols can stay connected in separate viewer windows. Connecting and reconnecting sessions reserve the same slot; changing a port or username does not bypass it.
- Each viewer keeps its own frames, input, connection recovery and cancellation. Closing one window or cancelling a new connection leaves other sessions running. Updates wait until all active sessions end.
- Native Removent and the optional VNC host can run concurrently. Their input coordinate mappings and session records are independent, and ending one session preserves the other in the host status list.
- Connection checks recognize normalized hostnames, resolved addresses and native host fingerprints across known routes. Separate relay rooms remain separate destinations.
- The CLI now provides inline keyboard menus and clearer terminal output. Saved connection forms no longer repeat the saved-credential hint.

The desktop app requires Apple Silicon and macOS 26 or later. RVP remains protocol v1. Relay packages retain Linux x86_64 / ARM64 and macOS Universal support.

Validation covers local Rust tests, GPUI multi-window tests and loopback QUIC/VNC connections. These checks do not establish complete multi-device screen, audio or WAN acceptance.

This GitHub prerelease does not upload or submit an iOS App Store build. The stable update channel remains on `0.1.5`; select Beta in Software Update to receive this release.
