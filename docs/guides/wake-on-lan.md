# Wake-on-LAN

桌面端可从目标的右键菜单选择「发送 Wake-on-LAN」。已保存连接的详情页「更多」菜单也提供此操作。

首次使用先配置：

- 目标网卡的 MAC 地址，支持冒号、短横线或连续 12 位十六进制格式。
- IPv4 发送地址，默认 `255.255.255.255`，也可指定目标子网的广播地址或可达的单播地址。
- UDP 端口，默认 `9`。

配置保存后，再次选择「发送 Wake-on-LAN」即可发送标准的 102 字节 magic packet。
发送成功表示本机已提交 UDP 数据报，不代表目标已唤醒。稍后自行连接目标；此操作不会自动连接。

附近发现的目标配置后会保存为连接，离线后仍能从已保存列表发包。RDP 发现目标需先填写账户并保存连接，再配置唤醒。
配置绑定到连接，仅保存在本机，不进入 iCloud 同步。修改连接地址会清除旧目标的唤醒配置。
「配置 Wake-on-LAN」中的「移除配置」只删除唤醒配置，保留连接和凭据。

目标硬件须支持网络唤醒，并在系统或固件中启用。Mac 需开启「唤醒以供网络访问」。
局域网广播是否有效取决于网卡、电源、网络接口和网络设备；Wi-Fi 唤醒需目标硬件支持。

唤醒包由当前控制端直接发送，不经 RVP 会话或公网中继。公网中继连接也可以配置此操作，
但发送地址仍须能从当前控制端所在网络到达。跨网唤醒通常需要目标局域网中的在线设备代发；本功能尚未实现代发。

参考：[Apple Remote Desktop 的唤醒要求](https://support.apple.com/en-tm/guide/remote-desktop/apd5535ee19/mac)。
