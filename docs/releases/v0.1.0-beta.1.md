Removent 的首个公开 beta，面向 **Apple Silicon Mac、macOS 13 及以上**。

Removent is a local-network remote desktop app for Apple Silicon Macs running macOS 13 or later.

### 安装 / Install

下载 DMG，双击打开，再双击 Removent，选择「安装并打开」；也可拖入 Applications。
Open the DMG, double-click Removent and choose **Install and Open**, or drag it to Applications.

首次共享屏幕或控制本机时，请按提示授予本地网络、屏幕录制和辅助功能权限。
Allow Local Network, Screen Recording and Accessibility when prompted for the features you use.

### 功能 / Features

- 局域网 mDNS 发现、手动地址连接和安全配对。
- 原生 QUIC 远程桌面，硬件 H.264/HEVC 编解码，音频与输入传输。
- 网络波动下动态码率、FPS、分辨率调整，以及逐步画质恢复。
- 临时断线恢复、取消与退出清理；VNC/RDP 客户端兼容路径。
- 中英文界面，后台服务与菜单栏控制。
- beta 更新检查，下载哈希、Ed25519 发布签名及 Developer ID 身份校验。

### Beta 限制 / Beta limitations

- 仅支持局域网；没有公网中继或 NAT 穿透。
- 首版仅提供 arm64，未提供 Intel 或 Universal 构建。
- mDNS 依赖系统本地网络权限和网络组播支持；若设备未出现，可使用手动地址连接。
- 不同 VNC/RDP 服务端、睡眠唤醒和真实弱网环境仍需更多 beta 验证。
- 自动检查更新，安装由用户发起；会话进行中推迟安装。beta 用户可升级到后续 beta 或正式版。

协议版本：RVP 1。本次增加的消息保持既有消息索引；双方使用同一 beta 可获得完整自适应画质功能。

Please report reproducible issues at https://github.com/backrunner/removent/issues, including macOS version, connection type and steps to reproduce. Do not include pairing PINs, passwords or private keys.
