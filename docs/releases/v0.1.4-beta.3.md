Removent `0.1.4-beta.3` refines settings, authenticator setup and LAN discovery. RVP remains protocol v1. The desktop app requires Apple Silicon and macOS 26 or later; the standalone relay supports Linux x86_64 / ARM64 and macOS Universal on macOS 13 or later.

## Settings and authentication

- Settings navigation is left aligned and uses a narrower sidebar. Light and dark surfaces use restrained borders, and Appearance shows a compact application preview.
- Selecting access-password authentication opens a focused editor with a placeholder, requirements and save feedback. The previous mode remains active until a valid password is saved; leaving the page discards the draft.
- OTP setup has its own card with separate scan and manual-entry sections. QR codes and keys stay hidden until requested, collapse on navigation, and share the host's existing SHA-1, six-digit, 30-second policy. Codes remain single-use.
- Mobile OTP entry supports the system one-time-code AutoFill field and provider guidance. Mobile settings include privacy, support and bundled open-source notices.

## LAN discovery

- Desktop and mobile discovery use Bonjour/mDNS service broadcasts for Removent, VNC and RDP. Subnet port scanning has been removed. Unadvertised devices can be added manually.
- Nearby devices already represented by direct saved connections are hidden using protocol, port and advertised IP/hostname aliases. Removing a bookmark restores any still-advertised device. Credentials, relay bookmarks and pairing trust are kept separate.
- The discovery shortcut is aligned at the bottom right of its empty-state card.

## Status and updates

- iCloud status uses compact badges and a right-aligned sync action. Zero pending changes are omitted, and the last successful sync shows local `HH:mm` time.
- The no-newer-version result appears only after a manual update check. Completed checks retain a local `HH:mm` timestamp across application restarts. Automatically discovered upgrades remain actionable above release notes.
- Background-component replacement and permission refresh from beta.2 remain in place.

## Website and review materials

- Bilingual support and privacy pages, bounded support intake with server-owned routing, and support regression checks are included in the source.
- iOS store-material preparation is kept separate from this desktop prerelease; this release does not submit the mobile app to App Store Connect.

This is a GitHub prerelease. Choose the Beta update channel or download this beta explicitly. Stable remains `0.1.3`; relay automatic updates continue to follow stable releases.
