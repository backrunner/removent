Removent `0.1.4-beta.2` improves automatic updates and permission status refresh. RVP protocol remains v1. The desktop app requires Apple Silicon and macOS 26 or later; the standalone relay supports Linux x86_64 / ARM64 and macOS Universal on macOS 13 or later.

## Automatic updates

- The download and install action appears above the release notes. Software Update is the first section in System settings.
- Updates restart the menu bar app and background service from the new app bundle before reopening Desktop. Service login preferences and an explicitly stopped service are preserved.
- Desktop refreshes an older menu bar process left running by previous installers. If relaunch fails, the updater restores the previous bundle and background components.

## Screen sharing permissions

- Desktop clears permission status while the background service is disconnected and refreshes it when the service returns, including when the permission grants are unchanged.
- Permission rows distinguish checking, disconnected, granted and missing states. Missing permissions provide a direct System Settings action and a concise setup hint.

This is a GitHub prerelease. Select the Beta update channel or download this beta explicitly. The latest stable release remains `0.1.3`; relay automatic updates continue to follow stable releases.
