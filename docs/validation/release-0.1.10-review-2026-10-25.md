# 0.1.10 发布审查

范围：原生协议双击识别、修饰键和键盘重复、滚动定位与结束、高频输入和断线释放。输入修复为签名提交 `9966ebc`，详见[输入验证记录](native-input-2026-10-24.md)。协议保持 v1。

## 本地验证

- 全工作区 Rust 测试 612 项通过、12 项忽略，串行执行用时 160.91 秒。
- 全工作区严格 Clippy、格式、布局、diff 空白和仓库 Python/shell 检查通过。保留已有 `block 0.1.6` future-incompatibility 提示及 Python 检查的一项既有跳过。
- 原生 QUIC 到真实 AppKit 窗口的 HID 输入验收已经通过，覆盖双击次数 `[1, 2]`、Shift 加右键、中键拖拽、键盘重复及滚动阶段。该项验收需要解锁的 macOS 桌面及辅助功能权限，常规 CI 默认忽略。
- 版本统一为 0.1.10，Cargo.lock 的 14 个工作区包及 iOS 源码版本元数据同步更新。iOS 仍使用独立分发流程。

## 发布门禁与边界

正式发布必须由同一提交的完整 CI 和 Relay 工作流通过，随后由发布脚本校验 Developer ID、Apple 公证、包结构、哈希和 Ed25519 更新清单签名，才上传公开安装包。

发布后还须下载公开 ZIP、DMG、三个 relay 平台包和更新清单，核对公开资源及 Stable 更新入口。源码测试和本机输入验收不等于跨机器 WAN 抖动、iPhone/iPad 真机手势、真实注销或重启验收。此次未执行本机或远端机器安装。
