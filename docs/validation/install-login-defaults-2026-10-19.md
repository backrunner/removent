# 安装默认开启后台服务登录启动

日期：2026-10-19。环境：本机 macOS。

## 行为

- 本地安装、发布版命令行安装，以及 DMG 安装或拖拽到 Applications 后首次打开应用，默认开启 removentd 的用户登录启动。
- 服务层统一处理安装默认值。显式启用或关闭登录启动时记录本地选择；后续安装或启动保留该选择，手动停止服务仍有效。开发目录中的应用不会通过安装器入口配置登录启动。
- 覆盖安装刷新已保留的 LaunchAgent 可执行文件路径，不因默认配置而中断已运行的会话。安装器原有活跃会话保护继续有效。
- 命令行 `--login` 显式开启登录启动，`--start` 仅启动并保留登录偏好，`--no-login` 关闭登录启动且首次安装不启动服务。没有图形登录会话时可用 `--no-login` 仅安装。
- 命令行安装对尚未提供 `daemon install-defaults` 的已发布 CLI 兼容回退到原有命令。当前版本的用户选择保留由服务层负责。
- 登录默认配置失败时撤回初始化标记，允许修复后重试；安装事务在服务配置完成后提交，再配置终端命令。
