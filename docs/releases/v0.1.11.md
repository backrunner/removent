Removent `0.1.11` improves native video presentation and real-time audio playback, and synchronizes the local clipboard before remote paste.

- Present H.264 and HEVC decoder surfaces directly through Metal on macOS, avoiding a full-frame CPU copy. Pace desktop rendering with display callbacks and measure frames actually presented. Reject frames whose declared geometry disagrees with their codec parameters.
- Move host video encoding onto a dedicated worker so synchronous hardware encoding does not occupy the asynchronous networking executor. Prioritize control and audio traffic ahead of video.
- Send every captured audio packet, wake decoding as packets arrive, and use bounded playback queues with clock-drift correction. Recover from stale retransmission bursts and avoid waiting for additional prebuffering when queued audio is close to its playback deadline.
- Replace locking and allocation in the desktop audio device callback with a shared bounded renderer. The same renderer and native video surface path are integrated into the iOS source; iOS distribution remains separate.
- Synchronize local clipboard text before sending the native remote-paste shortcut.

Update both the controller and the controlled Mac's app/background host for the complete media improvements. RVP protocol v1 is unchanged, with CPU video fallback retained where native surfaces are unavailable.

Local validation covers codec round trips and surface lifetime, audio timing and drift simulation, replay of captured network arrival timing, a real audio output callback, desktop presentation, and iOS simulator/device compilation. Initial wired two-Mac measurements still showed frame-rate variation and occasional audio underruns; the final audio adjustment has only been validated locally. This release does not claim sustained gaming-grade 60 FPS, measured input-to-display latency, or measured acoustic latency.

Software Update still checks periodically in the desktop app and requires manual download/install. Installation restarts the background host and tray while preserving an explicitly stopped host. A host running without the desktop app does not yet check for or install updates autonomously.

The desktop app requires Apple Silicon and macOS 26 or later. Standalone relay packages support Linux x86_64, Linux ARM64 and macOS Universal.
