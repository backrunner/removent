Removent `0.2.0` adds Windows and Linux desktop hosting and control, native trays, secure saved credentials, and a macOS Computer Use MCP server.

### Added

- Windows x86_64 and Linux x86_64 portable desktop packages with the application, background host and native tray. Sessions support H.264/AV1 CPU video, keyboard and mouse input including Chinese text, and bidirectional text clipboard sharing. Updated macOS hosts negotiate H.264 with these controllers.
- Native tray actions for sharing, pairing and access requests, with crash recovery, persistent manual stop and restoration of the existing desktop window. Closing the main window leaves sharing available; quitting only the tray preserves active connections.
- Windows account and Linux PAM authentication tied to the user running the desktop host. Optional saved credentials use Windows Credential Manager or Linux Secret Service, with editing, removal and automatic reuse for the same verified host. Passwords are not stored in connection files or synced.
- A bundled macOS `removent-mcp` server can connect to trusted saved hosts, share existing desktop sessions, inspect remote Accessibility elements and screenshots, and perform native or coordinate actions. The host requires explicit peer authorization and system permissions. Human input pauses automation; resuming requires an explicit request. Unavailable input monitoring blocks automation changes. See [Computer Use setup](https://github.com/backrunner/removent/blob/v0.2.0/docs/guides/computer-use-mcp.md).

### Fixed

- Windows log locking, concurrent settings replacement, connection-journal persistence and application-local Visual C++ runtime packaging.
- Linux presentation on CPU-only Mesa desktops, portable native dialogs, sharing toggles during status refreshes, and recovery after shell or host restarts.

### Downloads and requirements

- **macOS:** `Removent-0.2.0-macos-arm64.dmg` or `.zip`, Developer ID signed and notarized. Requires Apple Silicon and macOS 26+. Existing Stable users receive the signed update through the current updater.
- **Windows:** `Removent-windows-x86_64.zip` and its `.sha256`. Extract the entire archive and run `removent.exe`; keep the included runtime DLLs alongside it. This is an unsigned portable build, so Windows may show a publisher warning. It requires an interactive signed-in desktop and cannot control UAC or the sign-in screen.
- **Linux:** `Removent-linux-x86_64.tar.gz` and its `.sha256`. Requires glibc 2.39+ (Ubuntu 24.04 or newer), desktop runtime libraries and an AppIndicator-capable panel. Hosting requires X11. See [runtime dependencies and usage](https://github.com/backrunner/removent/blob/v0.2.0/docs/guides/windows-linux.md).
- Standalone relay archives and signed relay update manifests remain available for Linux x86_64, Linux ARM64 and macOS Universal.

Windows/Linux packages require manual replacement for updates and do not include system-audio capture, pre-login access, native Computer Use or idle-sleep prevention. They are not Windows installers or distribution-managed Linux packages. Browser DOM automation is unavailable. Native acceptance used Windows Explorer and Linux X11/Xfce virtual desktops; physical GPU/monitor changes, WAN conditions, multi-day uptime and real two-computer MCP operation remain unverified. iOS source metadata is updated; this release does not publish an App Store or TestFlight build.

RVP protocol remains v1. Update both desktop endpoints for H.264 interoperability and update both macOS endpoints before enabling Computer Use.
