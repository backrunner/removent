Removent `0.1.5` is a stable patch release that fixes this computer appearing in nearby discovery, including its VNC service at `127.0.0.1:5900`.

- Desktop and mobile use the same address policy for Removent, VNC and RDP. Nearby lists exclude loopback, unspecified addresses and assigned local interface addresses, including IPv4-mapped IPv6.
- IPv6 link-local comparisons preserve interface scope. A remote computer with the same display name remains discoverable. If a remote advertisement includes a loopback alias, discovery selects its valid remote address instead.
- Nearby lists recheck local interfaces every two seconds so address changes remove stale self entries. Explicit connections, saved connections and typed invitation lookup retain their connection behavior.

The desktop app requires Apple Silicon and macOS 26 or later. RVP remains protocol v1. The relay packages are versioned with this release and retain Linux x86_64 / ARM64 and macOS Universal support.

The mobile source is `0.1.5` (6). This GitHub release does not upload or submit an iOS App Store build.
