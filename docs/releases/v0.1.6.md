Removent `0.1.6` is the stable release of the `0.1.6` beta series. It improves native remote sessions, introduces per-connection video quality limits, and makes unattended Mac hosting more predictable.

- Native Removent, VNC, and RDP sessions now use independent desktop windows and state. One machine can have one active session per protocol while sessions to other machines or protocols continue separately.
- Remote video startup and recovery handle sleeping or changing displays, capture interruptions, and video delivery stalls. The host reports capture failures instead of leaving the controller waiting indefinitely. A missing or ended audio stream does not close healthy video.
- New native connections can choose Low, Standard, High (2K), or Ultra (4K) as a quality ceiling. The host adapts resolution, bitrate, and frame rate to the selected range and current delivery conditions. Compatible peers can negotiate up to 4K and 240 fps, subject to the display, hardware, codec, and connection; this is a capability limit, not a performance guarantee. Older peers retain the previous video negotiation.
- The host can keep macOS from entering idle system sleep while the background service runs. This setting is off by default and does not override manual sleep or lid closure. An active session also keeps its capture display awake.
- The desktop update screen places the install action beside the available version and presents long release notes in a scrollable reading area. The CLI adds keyboard menus and clearer terminal output.
- The `0.1.6-beta.1` fixes for decoded-frame rendering, ScreenCaptureKit audio formats, and long UTF-8 device names are included.

The desktop app requires Apple Silicon and macOS 26 or later. RVP remains protocol v1. Standalone relay packages support Linux x86_64, Linux ARM64, and macOS Universal. Update the host as well as the controller to use the new video and capture features.

This GitHub release does not upload or submit an iOS App Store build. Mobile source changes remain on the separate iOS release track.
